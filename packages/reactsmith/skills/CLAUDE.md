## ReactSmith

This project's structure and UI are managed by ReactSmith. For any change to pages, layouts, components, elements, styles, icons or constants, use the `reactsmith` skill and its commands (`npx reactsmith … --json`), not hand edits. Write only logic by hand. Run `npx reactsmith check` when done.

To build from the design (`design.figma` in `reactsmith.config.json`), use the `reactsmith-from-figma` skill: it writes `reactsmith-plan.md` for review before running anything.
